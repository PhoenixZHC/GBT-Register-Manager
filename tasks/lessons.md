# Lessons

- 2026-10-12：程序不存在与点位不存在必须独立分类；前者中止并提示检查程序名，后者才可能允许新增点位。用户验收反馈记录日期和原话，关闭当前待测项但不改写历史失败证据。

- 记录已确认、可复用的工程经验；测试成功不代表机器人实机验收。
- 2026-06-15：用户指出文档中文被写成乱码；后续修改含中文文件时必须先确认编码，避免用会改写编码的批量 Set-Content 覆盖文档。
- 2026-10-09：异步写入先固定会话、类型、程序名及数据；UI 禁用只是辅助，不能代替参数快照。
- 2026-10-09：SDK 读取失败不能等同于数据不存在；只接受明确的不存在状态码，其他错误阻止后续写入。
- 2026-10-09：Excel 校验前保留原始数值，不能先舍入小数 ID 或将非有限数替换成零。
- 2026-10-09：导出文件完成并同步后才替换目标，空结果或打包失败必须保留旧文件。
- 2026-10-09：原生进程和 SSH 阻塞调用都需要时间上限；超时不意味着写入未发生，不自动重试。
- 2026-10-09：无可靠枚举接口时用明确范围，不用连续空编号猜测结束；构建每一步检查退出码，禁止失败后复制旧包。
- 2026-10-10：不能假设 SDK 把空 R/PR 统一为 NOT_FOUND。GBT-S6A-600 固件 1.5.7 实测返回动态 REG_MANAGER_INVALID_ARG / 0001000200A40007，测试应包含实际返回结构。恢复旧版扫描时明确标注连续空编号截止规则，不将近似扫描说成完整枚举。
