## 概述

本软件为 **捷勃特（Agilebot）** 机器人桌面工具：在已连接控制器的前提下，可 **批量操作 R、PR、P 寄存器**（Excel 导入导出、批量新建），并可通过 **SFTP** 从控制柜 / 示教器 **按日期导出日志**、从控制柜 **导出程序数据（robot_data）**，无需再使用 WinSCP 手工下载。

当前软件版本：`v1.1.1`

## 兼容 SDK 版本说明

捷勃特 Agilebot Python SDK | v2.0.1.0

## 功能列表

1. **R / P / PR 寄存器操作**：支持数值寄存器 **R**、位姿寄存器 **PR**、程序点 **P**；操作 **P** 时需填写与控制器一致的 **程序名**。

| 类型 | 含义 | 额外填写 |
|------|------|----------|
| **R** | 数值寄存器 | 无 |
| **PR** | 位姿寄存器 | 无 |
| **P** | 程序点（程序中的位姿） | **程序名** |

2. **批量新建**：按 **起始 ID** 与 **数量** 连续创建指定类型寄存器；类型为 **P** 时需程序名，并受下文「使用注意」限制。

3. **寄存器数据导出**：按 **指定区间** 或 **全部** 从机器人读取，表格预览，可 **导出为 Excel**；其中 **「全部」** 从寄存器 **ID 1** 起依次读取，若出现 **连续 10 次** 读取失败则停止，并返回此前所有读取成功的记录（适用于从 1 起连续有数据的场景）。

4. **寄存器数据导入**：**导入 Excel** 预览后 **写入机器人**；目标 ID 已存在时可选择 **覆盖**、**跳过已存在** 或 **终止**。支持 **导出模板**（仅表头）供离线填写。

5. **日志 / 程序与数据导出**（须 **已成功连接** 机器人，且非调试绕过 IP）：
   - **导出控制柜日志**：按所选公历日期，从 `/root/log` 仅导出纯时间戳文件名 `YYYYMMDDHHmmss.log`；从 `/root/app_log` 导出文件名中含所选日期的各服务 `.log` 文件；合并打包为 ZIP。
   - **导出示教器日志**：按所选公历日期，从示教器 `/root/app_log` 导出文件名中含所选日期的各服务 `.log` 文件并打包为 ZIP（需连接时已填写 **示教器 IP**）。
   - **导出程序数据**：从控制柜递归下载 `/root/robot_data` 为 ZIP（不依赖日期）。  
   SFTP 账号密码在源码 `src-tauri/src/sftp_export.rs` 中配置；导出前请将 **控制柜 / 示教器** 密码按实机填写。

6. **多语言界面**：顶部可切换 **中文**、**English**、**日本語**、**한국어**、**Русский**。

## 使用步骤（常见流程）

1. 打开软件，输入 **控制柜 IP**（可选填 **示教器 IP**），点击 **连接**（连接路径使用 SDK 本地代理，便于访问 **P** 寄存器等服务端口）。
2. 在左侧选择：**批量新建**、**寄存器数据导出**、**寄存器数据导入** 或 **日志/程序与数据导出**。
3. 寄存器相关页：先选定 **R / P / PR**；若为 **P**，在需要处填写 **程序名**。
4. **只做寄存器表导出**：设好区间或「全部」→ **从机器人读取** → 核对表格 → 需要时 **导出为 Excel**。
5. **从表写入**：**导入 Excel**（或读取后改表）→ **写入机器人** → 按提示处理冲突。
6. **日志 / 程序与数据**：在 **日志/程序与数据导出** 页选择日期（日志用）→ 点击对应按钮 → 在对话框中选择保存的 ZIP 路径。
7. 用完后在顶部点击 **断开连接**。

## Excel 表格式

- 使用 **第一个工作表**；**第 1 行为表头**，从 **第 2 行** 起为数据。
- 建议先用软件内的 **导出模板**，避免表头错误。

**R** 表头：`type`，`ID`，`value`  

**P** 表头：`Type`，`ID`，`X`，`Y`，`Z`，`A`，`B`，`C`，`TF`，`UF`，`Coord`  

**PR** 表头：`TYPE`，`ID`，`X`，`Y`，`Z`，`A`，`B`，`C`，`coord`  

## 使用注意（正式使用前请阅读）

- **「读取全部」**：并非固定 ID 上限，而是从 **ID 1** 起按顺序逐个读取；每当某次读取失败，累计连续失败次数，**连续失败满 10 次**即停止扫描，只保留此前成功读到的数据。若寄存器编号不连续、中间有大量空洞，结果可能早于真实最大 ID 就结束；此时请改用 **指定范围** 读取。为防止单次扫描过久，实现上设有 **ID 上限（100000）**，到达上限也会停止。

- **`/root/app_log` 日期匹配**：按所选公历日的 `YYYYMMDD` 在文件名中匹配；要求该 8 位数字前后不能紧贴其它数字，以免误匹配（例如 `service_202605111.log` 不会当作 5 月 11 日）。
